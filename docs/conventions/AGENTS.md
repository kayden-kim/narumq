# 코드·저장소 작성 규칙

[상위 규칙](../AGENTS.md)을 따르며 다음을 추가한다.

## 시작 템플릿

- 공통 컨벤션은 [컨벤션 템플릿](../templates/convention.template.md)을 사용한다.
- 디자인 기준은 [DESIGN 템플릿](../templates/DESIGN.template.md)을 사용한다.
- 프런트엔드 코드 작성 규칙은 [프런트엔드 템플릿](../templates/frontend.template.md)을 사용한다.

- 공식 언어 명세, 공식 포매터와 관례를 프로젝트 규칙보다 우선한다.
- 구조 문서가 정한 경계를 바꾸거나 제품 동작을 새로 정의하지 않는다.
- 허용·금지 예시와 판단 기준을 함께 제시하고, 자동 검증(린트, 포매터, 테스트) 명령과 성공 조건을 함께 적는다.
