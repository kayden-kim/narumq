# how-to 작성 규칙

[상위 규칙](../AGENTS.md)을 따르며 다음을 추가한다.

## 시작 템플릿

[how-to 템플릿](../templates/how-to.template.md)으로 실행·검증·운영 절차를 작성한다.

## 작성 규칙

- 한 단계에는 하나의 행동과 기대 결과를 둔다. 파괴적 단계 직전에 영향과 복구 가능 여부를 표시한다.
- 실제 환경에서 실행·대조하지 않은 절차를 `Verified`로 표시하지 않는다.
- 결과와 증거는 [검증 기록](../AGENTS.md#검증-기록)을 따른다.
- 명령줄에 비밀번호나 인증 키 등 비밀 값을 노출하지 않는다.
