# 해설 작성 규칙

[상위 규칙](../AGENTS.md)을 따르며 다음을 추가한다.

## 시작 템플릿

[해설 템플릿](../templates/explainer.template.md)으로 개념과 코드 흐름을 설명한다.

## 작성 규칙

- 신입 개발자가 이해하도록 문제 상황과 필요한 개념부터 설명한다. 정상 흐름 뒤에 실패 흐름을 설명한다.
- 코드 구조와 처리 순서의 기준은 코드 지도와 모듈 설계에 둔다. 해설은 그 문서를 링크해 개념과 선택의 이유를 설명하고, 실제 코드에서 개념이 드러나는 지점을 따라 읽는 방법을 안내한다.
- 반드시 지켜야 하는 요구사항, 구조 결정, 작업 절차를 새로 만들지 않고 기존 기준 문서를 연결한다.
- 실패 후 남는 상태, 재시도 가능 여부, 상태 관리 주체와 생성/제거 시점을 명시한다.
