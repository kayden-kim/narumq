# 기술 해설 작성 규칙

[상위 규칙](../AGENTS.md)을 따르며 다음을 추가한다.

- 주니어 개발자가 독립적으로 이해할 수 있도록 배경과 구체적 문제 상황에서 출발해 정상/실패 흐름 순으로 설명한다.
- 바이브 코딩(AI 생성 코드) 과정에서 놓치기 쉬운 전체 코드 구조, 데이터·제어 흐름, 주요 초기화·로딩(Lifecycle) 시점과 맥락을 함께 다룬다.
- 반드시 지켜야 하는 요구사항, 구조 결정, 실행 절차를 새로 만들지 않고 기존 기준 문서를 연결한다.
- 실패 후 남는 상태, 재시도 가능 여부, 상태 관리 주체와 생성/제거 시점을 명시한다.
