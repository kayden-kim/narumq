# {{프로젝트명}} 코드 지도

{{실제 source가 어떤 주요 실행 진입점에서 시작해 대표 요청을 거치는지 2~3문장으로 쓴다. 목표 설계가 아니라 확인한 파일과 심볼을 기준으로 한다.}}

관점 상태를 `Current`로 표시하려면 실제 구현 증거를 먼저 대조한다. 최소한 기재한 source 파일과 심볼이 현재 코드에 있는지 확인하고, 동작을 주장할 때는 관련 test·manifest 등 근거도 연결한다. 대조 전에는 `Current`로 표시하지 않는다. 관점 상태와 문서 상태는 별도이며, `Verified` 표기는 [architecture 문서 작성 규칙](AGENTS.md)의 증거 대조 기준을 따른다.
