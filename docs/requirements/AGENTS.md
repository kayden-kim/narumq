# PRD 작성 규칙

[상위 규칙](../AGENTS.md)을 따르며 다음을 추가한다.

## 시작 템플릿

[PRD 템플릿](../templates/PRD.template.md)으로 제품 요구사항을 작성한다.

## 작성 규칙

- 각 독립 요구사항에는 고유하고 안정된 ID를 부여하고, ID당 하나의 검증 가능한 결과만 둔다.
- 상세 동작은 `specs/`, 교환 형식은 `contracts/`, 기술 선택은 `decisions/`로 분리한다.
- 수용 기준은 스펙의 문서 경로와 시나리오 ID에 연결한다. 테스트 결과는 복제하지 않고 [검증 기록](../AGENTS.md#검증-기록)에 따른 커버리지·결과 보고서를 참조한다.
- 업무 용어는 [용어집 유지보수](../AGENTS.md#용어집-유지보수)에 따라 PRD를 쓰는 시점에 확정한다.
