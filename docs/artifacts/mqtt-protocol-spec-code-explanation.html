04 · Decode

Decoder는 작은 검증 pipeline이다

입력 확인

nil decoder나 빈 입력이면 ErrIncompletePacket입니다.

Fixed Header 확인

상위 4비트에서 packet type을 얻고, 하위 flag가 해당 packet 규칙과 맞는지 확인합니다.

Version context 확인

CONNECT만 ProtocolUnknown으로 시작할 수 있습니다. CONNACK, PUBLISH와 ACK packet은 caller가 version을 제공해야 합니다.

Remaining Length 확인

canonical variable-byte encoding인지 확인하고, 설정된 limit를 body slice보다 먼저 검사합니다.

Packet별 decoder 호출

CONNECT, CONNACK, PUBLISH, PUBACK/PUBREC/PUBREL/PUBCOMP, SUBSCRIBE/SUBACK/UNSUBSCRIBE/UNSUBACK와 PINGREQ/PINGRESP/DISCONNECT로 dispatch합니다. 성공하면 첫 frame의 소비 byte 수를 반환합니다.

remainingLength, lengthBytes, err := decodeVariableByteInteger(src[1:])
if err != nil {
    return nil, 0, err
}
if remainingLength > d.maxPacketSize {
    return nil, 0, ErrPacketTooLarge
}

frameHeaderLength := 1 + lengthBytes
if remainingLength > len(src)-frameHeaderLength {
    return nil, 0, ErrIncompletePacket
}

body := src[frameHeaderLength : frameHeaderLength+remainingLength]

decoder.go:36-47

유효하지만 일부만 지원

QoS 1·2 wire packet, subscription packet과 ACK는 지원하지만 Receive Maximum, shared/retained routing과 durable storage 정책은 아직 바깥 application 경계에 있습니다.

문법 자체가 잘못됨

QoS 3, Packet Identifier 0, reserved flag, non-canonical length는 ErrMalformedPacket입니다.

06 · Encode order

Encoder의 실제 순서: validate → size check → body 생성

1validateConnect(connect)→ bodySize 계산
2bodySize > maxPacketSize→ ErrPacketTooLarge
3make([]byte, 0, bodySize)검증된 크기로 body buffer 생성
4protocol name·flags·fields appendcanonical body 작성
5fixed header·Remaining Length appendcaller의 dst 뒤에 최종 frame 추가

    ...

07 · Packet rules

Packet별 제한

CONNECT

  • MQTT / level 4·5 version discovery
  • flags, Will QoS, username/password 관계 검증
  • MQTT 5 Session Expiry 0x11를 한 번만 해석
  • MQTT 3.1.1 nonzero Session Expiry 거부
  • trailing byte와 알 수 없는 property 거부

CONNACK

  • version별 body 길이 검증
  • version별 reason code allowlist
  • 실패 reason과 Session Present 모순 거부
  • MQTT 5 property length 0만 지원

PUBLISH

  • QoS 0·1·2와 Packet Identifier 검증
  • QoS 0 DUP 금지, QoS 1·2 재전송 flag 보존
  • Topic Name wildcard 금지와 payload copy
  • MQTT 5 property-free PUBLISH profile

ACK packets

  • PUBACK/PUBREC/PUBREL/PUBCOMP fixed-header flags
  • MQTT 3.1.1 exact success body
  • MQTT 5 implicit success와 reason allowlist
  • success wire를 Remaining Length 2로 canonicalize

SUBSCRIBE 계열

  • SUBSCRIBE/SUBACK/UNSUBSCRIBE/UNSUBACK fixed flags
  • ordered filters와 MQTT 5 option·reason allowlist
  • MQTT 5 property-free profile와 input ownership
  • invalid filter·shared·deferred option의 명시적 ACK reason

Routing & queue

  • non-shared +·# wildcard matching
  • system topic 경계와 session별 overlap one-copy
  • publisher/subscription QoS 최솟값 계산
  • session별 fixed item capacity와 FIFO drain
