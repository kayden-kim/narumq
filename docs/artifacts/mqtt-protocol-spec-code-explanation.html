04 · Decode

Decoder는 작은 검증 pipeline이다

입력 확인

nil decoder나 빈 입력이면 ErrIncompletePacket입니다.

Fixed Header 확인

상위 4비트에서 packet type을 얻고, 하위 flag가 해당 packet 규칙과 맞는지 확인합니다.

Version context 확인

CONNECT만 ProtocolUnknown으로 시작할 수 있습니다. CONNACK과 PUBLISH는 caller가 version을 제공해야 합니다.

Remaining Length 확인

canonical variable-byte encoding인지 확인하고, 설정된 limit를 body slice보다 먼저 검사합니다.

Packet별 decoder 호출

CONNECT, CONNACK, PUBLISH로 dispatch합니다. 성공하면 첫 frame의 소비 byte 수를 반환합니다.

remainingLength, lengthBytes, err := decodeVariableByteInteger(src[1:])
if err != nil {
    return nil, 0, err
}
if remainingLength > d.maxPacketSize {
    return nil, 0, ErrPacketTooLarge
}

frameHeaderLength := 1 + lengthBytes
if remainingLength > len(src)-frameHeaderLength {
    return nil, 0, ErrIncompletePacket
}

body := src[frameHeaderLength : frameHeaderLength+remainingLength]

decoder.go:36-47

유효하지만 아직 미지원

PUBLISH QoS 1·2는 MQTT상 유효하므로 ErrUnsupportedQoS로 분류합니다.

문법 자체가 잘못됨

QoS 3, reserved flag, non-canonical length는 ErrMalformedPacket입니다.

06 · Encode order

Encoder의 실제 순서: validate → size check → body 생성

여기서 중요한 구현 순서는 body를 만들기 전에 validation과 크기 검사를 끝낸다는 점입니다. encodeConnect의 실제 흐름은 다음과 같습니다.

1validateConnect(connect)→ bodySize 계산
2bodySize > maxPacketSize→ ErrPacketTooLarge
3make([]byte, 0, bodySize)검증된 크기로 body buffer 생성
4protocol name·flags·fields appendcanonical body 작성
5fixed header·Remaining Length appendcaller의 dst 뒤에 최종 frame 추가
func encodeConnect(connect Connect, maxPacketSize int) ([]byte, error) {
    bodySize, err := validateConnect(connect)
    if err != nil {
        return nil, err
    }
    if bodySize > maxPacketSize {
        return nil, ErrPacketTooLarge
    }

    body := make([]byte, 0, bodySize)
    // protocol name, level, flags, fields를 body에 append
    ...
}

07 · Packet rules

Packet별 제한

CONNECT

  • MQTT / level 4·5 version discovery
  • flags, Will QoS, username/password 관계 검증
  • MQTT 5 property length 0만 지원
  • MQTT 3.1.1 빈 Client ID 조건 검증
  • trailing byte 거부

CONNACK

  • version별 body 길이 검증
  • version별 reason code allowlist
  • 실패 reason과 Session Present 모순 거부
  • MQTT 5 property length 0만 지원

PUBLISH

  • QoS 0만 지원
  • retain은 지원, DUP=1은 거부
  • Topic Name에 wildcard 금지
  • payload는 binary로 복사
  • MQTT 5 property length 0만 지원
