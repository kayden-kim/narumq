# 기술 결정 기록(ADR) 작성 규칙

[상위 규칙](../AGENTS.md)을 따르며 다음을 추가한다.

## 시작 템플릿

[ADR 템플릿](../templates/ADR-0000-template.md)을 복제해 새 기술 결정을 기록한다.

- 채택된 결정(`Accepted`)은 수정하지 않고, 새 ADR로 대체(Superseded)하며 양방향 링크를 건다.
- 대안은 동일한 결정 요인으로 비교하고, 긍정적·부정적 영향과 후속 작업을 함께 기록한다.
- 제품 요구사항, 상세 외부 동작, 실행 절차를 ADR에 복제하지 않는다.
