# Raft failure-bound 증거 이후 잔여 작업

이 목록은 [cluster 수용 시험](specs/cluster-session-and-delivery.md#11-수용-시험)과 [ADR-0002 §7](decisions/ADR-0002-cluster-consensus-library.md#7-검증)에서 in-process WAL 쓰기 실패·느린 follower 및 backup v1/v2 process acceptance만으로 닫히지 않은 작업을 추린 것이다. 프로젝트 전체 백로그가 아니며 동작과 완료 판정의 기준은 링크한 스펙·결정 기록이다.

## Production 경계와 설계 결정

- [x] [ADR-0002 §7 항목 5](decisions/ADR-0002-cluster-consensus-library.md#7-검증): 고정 voter `{1,2,3}`의 production peer-only transport, mTLS 인증·framing, bounded queue/backpressure와 Raft 재생성을 구현·검증했다. Evidence는 [Cluster §11.3](specs/cluster-session-and-delivery.md#113-phase-0-gate-4-production-peer-transport-mapping)에 연결한다. 이 항목은 ADR-0002의 Proposed 상태, dynamic membership 또는 전체 cluster 수용 완료를 뜻하지 않는다. 기존 시험의 미응답 entry-bearing `MsgApp` 범위 16개 이하는 전송 대기열 또는 전체 Raft log 한계가 아니다.
- [x] [Cluster architecture의 미결정 사항](architectures/cluster-architecture.md#미결정-사항): production consensus module version/checksum, WAL·snapshot storage engine 및 `fsync`, replicated state encoding, group partition 전략을 scoped design target으로 [ADR-0009](decisions/ADR-0009-raft-production-state-profile.md)에 결정·기록했다. `go mod verify`는 `all modules verified`였고, `go mod download -json go.etcd.io/raft/v3@v3.7.0`의 `Sum`·`GoModSum`은 `go.sum`과 일치한다. 이는 설계와 dependency checksum 확인만 완료한 것이며 production durability·전체 CLU-14 backup/restore·quorum ACK·N/N-1 compatibility나 전체 runtime 수용 완료를 뜻하지 않는다. 고정 voter transport v1의 peer RPC와 node identity 결정은 [ADR-0008](decisions/ADR-0008-raft-peer-transport.md)에 한정된다. [ADR-0002](decisions/ADR-0002-cluster-consensus-library.md)는 계속 `Proposed`다.
- [x] [Cluster membership](specs/cluster-session-and-delivery.md#1-cluster-membership)과 [ADR-0002 §7 항목 6](decisions/ADR-0002-cluster-consensus-library.md#7-검증): join·leave, member 인증·호환성 검사와 membership 변경 중 crash/restart 수렴을 구현·시험했다. 동기화, route projection rebuild 및 quorum 확인 전 MQTT readiness 거절을 검증했다. [Cluster §11.5](specs/cluster-session-and-delivery.md#115-dynamic-membershiprestart-convergencemqtt-readiness-mapping)에 수용 증거를 기록했으며 `go run ./tools/verify local`이 PASS였다(전체 production line coverage 91.59%). 다른 cluster production 수용 기준은 아래 열린 항목으로 유지한다.
- [x] PRD TEN-08 scoped quota implementation and acceptance: [ADR-0017](decisions/ADR-0017-tenant-storage-quota.md)가 quota model과 한도를 고정했다. Membership profile·usage·admission·snapshot replay, replicated command/snapshot codec, cluster record conversion, strict config/controller/readiness, bounded metrics와 실제 3-node process acceptance를 구현·검증했다. Readiness 회귀 시험과 `GOMAXPROCS=4 go run ./tools/verify local`도 PASS했다. 상세 실행 증거는 [Cluster §11.16](specs/cluster-session-and-delivery.md#1116-tenant-storage-quota-수용-매핑)에 있다. Linux/EBS production gate와 N/N-1 compatibility는 별도 미완료 항목이다.
